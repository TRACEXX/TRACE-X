DETECTIVE PROFILE PHOTOS
========================
Until a photo is set, each detective is shown with their initials.

1. Copy a square photo here, for example:  amna.jpg  warisha.jpg  hiba.jpg  maryam.jpg
2. Log in as the administrator -> User accounts.
3. Set "Profile photo" to the path inside static/, e.g.  assets/detectives/amna.jpg
4. Save. No code changes are needed.
